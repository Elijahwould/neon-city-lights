##### Source: Unearthed Arcana 7 - Modern Magic (Arcane Hacking)

*2nd-level manipulation*

**Casting Time:** 1 action

**Range:** Self

**Components:** V, S, M (hacking tools)

**Duration:** Concentration, up to 1 hour

You gain advantage on all Intelligence checks using hacking tools to break software encryption or online security when using a foreign system.

This tech also allows you to break 2nd level and lower protective techs such as *[programmed lock](/tech:programmed-lock)* or *[booby trap](/tech:booby-trap)* by making an Intelligence check using hacking tools against the tech save DC of the tech’s caster.

***At Higher Levels.*** When you cast this tech using a tech slot of 3rd level or higher, you can attempt to counteract a tech set to secure the foreign system if the tech’s level is equal to or less than the level of the tech slot you used.
