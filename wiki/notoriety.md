## "Notoriety wasn't as good as fame… but it was heaps better than obscurity."

Notoriety is a side-currency in Neon City Nights. Notoriety is earned by contributing to Neon City Nights in many different ways: running games as a fixer, submitting lore, submitting homebrew, submitting fixes to the wiki or suggestions that get used, and so on.

Notoriety gain and expenditure is tracked in a separate channel (**#notoriety-tracking**). As of right now, here is a menu of things you can spend notoriety on:

*Notoriety Costs*

| Cost | Amt. Buyable | Description |
| --- | --- | --- |
| 5 | 4/rank | Rank Credits on one character |
| 5 | ∞ | Change one Tech Known for a character w/the Techcasting feature |
| 10 | ∞ | Change a character's ASI or Feat |
| 10 | ∞ | Rank Credits on a Street Legend+ character |
| 10 | ∞ | 1 MP and Rank Credits on one character |
| 20 | 1/month | Change a character's subclass |
| 20 | 1/year | Change a character's lineage, as per the *[transcreation](/tech:transcreation)* tech |
| 30 | 1/month | Change a character's class |
| 40 | Creation | During character creation, roll an additional *.threshold* to select from |
| 50 | 1/months | Reassign base ability scores |
| 150 | 1/player | Unlock an additional character slot |
| 300 | 1/player | Unlock an additional character slot |
| 300 | 1/player | Unlock an additional townie slot |
| 400 | 1/character | Unretire a previously retired character |
| 600 | 1/player | Unlock an additional character slot |
| 600 | 1/player | Unlock an additional townie slot |
