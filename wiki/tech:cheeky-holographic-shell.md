##### Source: Player's Handbook (Nystul's Magic Aura)

*2nd-level deception*

**Casting Time:** 1 action

**Range:** Touch

**Components:** V, S, M (a tiny remote projector)

**Duration:** 24 hours

You project a hologram on a creature or an object you touch so that observation techs reveal false information about it. The target can be a willing creature or an object that isn't being carried or worn by another creature. When you cast the tech, choose one or both of the following effects. The effect lasts for the duration. If you cast this tech on the same creature or object every day for 30 days, placing the same effect on it each time, the deception lasts until it is dissipated.

When you cast the tech, choose one or both of the following effects. The effect lasts for the duration. If you cast this tech on the same creature or object every day for 30 days, placing the same effect on it each time, the illusion lasts until it is dissipated.

***False Reading.*** You change the way the target appears to techs and technical effects, such as *[anomaly detector](/tech:anomaly-detector)*, that detect technical readings. You can make a nontechnical object appear technical, a technical object appear nontechnical, or change the object’s technical reading so that it appears to belong to a specific school of tech that you choose. When you use this effect on an object, you can make the false tech apparent to any creature that handles the item.

***Mask.*** You change the way the target appears to techs and technical effects that detect creature types, such as a enforcer’s Techno-Sense or the trigger of a safety setup tech. You choose a creature type and other techs and technical effects treat the target as if it were a creature of that type or of that alignment.
