##### Source: Unearthed Arcana (System Backdoor)

*4th-level manipulation*

**Casting Time:** 1 minute

**Range:** Self

**Components:** V, S, M (Hacking tools)

**Duration:** Concentration, up to 1 hour

This tech allows you to bypass system security in order to create a secure login on a foreign system. The login you create allows you administrator-level privileges in any computer system not enhanced through technomagic. The login defeats any technomagic tech of 3rd level or lower.

Once the duration of the tech expires, the login and all privileges are wiped from the system. System logs still show the activity of the user, but the user identification cannot be found or traced.

***At Higher Levels.*** When you cast this tech using a tech slot of 5th level or higher, you are able to bypass technomagic tech if the tech's level is equal to or less than the level of the tech slot you used.
