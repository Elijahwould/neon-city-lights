*Consumable (substance), legendary*

(Flavor Text TBD)

This viscous, milky-white substance can form a permanent adhesive bond between any two objects. It must be stored in a container that has been coated inside with [NANiTE™ Slip-n-Slide Hyperlubricant](/consumable:nanite-slip-n-slide-hyperlubricant). When found, a container contains 1d6 + 1 ounces. One ounce of the glue can cover a 1-foot square surface. The glue takes 1 minute to set. Once it has done so, the bond it creates can be broken only by the application of [The Mistake™](/consumable:the-mistake) or [Eternal Thread™ Essence of the Etherealnet](/consumable:eternal-thread-essence-of-the-etherealnet), or with an [Absolute Source Code Manipulation](/tech:absolute-source-code-manipulation) tech.
