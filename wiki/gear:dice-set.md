A dice set is, well, a set of dice. They can be many different kinds: a full RPG set (including a d20, d12, 2 d10s for percentile, a d8, a d6 and a d4), a little collection of six d6s, or any variation you might like. Many different games can be played with a dice set: Liar's Dice, Yahtzee, etc. and a user proficient with this set is assumed to be proficient in them.
